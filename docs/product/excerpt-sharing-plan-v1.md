## Goal / Context / Constraints / Done when

Goal：接收者能看到允许分享的精确摘录、文档版本/哈希/页/定位及参数适用条件；没有明确有效声明的摘录不进入分享包，并明确提示缺失。
Context：现有FieldSource含原文，但没有分享声明。run_provenance保存完整profile values；当前、历史、chat fact conditions和source coverage都可能携带原文。隐藏卡片不足以过滤嵌套出口。
Constraints：仅公开/合成来源；不自动下载或复制PDF；分享声明是人工声明而非权利认证；模型不能授予许可或电气批准；本地原记录/历史不改写；旧记录没有许可不得自动补造。完整备份用于保留本地项目，必须与分享报告清晰区分。
Done when：人工可录入/更正并声明允许或不允许；声明绑定精确来源内容，改变来源任一维度即失效；可分享项保持原参数/条件可追溯，未声明/撤回/失效项当前与历史出口均明确省略；离线HTML及内嵌JSON/清单/聊天路径不存在遗漏；本地恢复仍保留原值；生产批准和历史不被新元数据隐式改变；真实独立核对仍须真实人完成。

## 实施顺序

1. 基础合同：FieldSource可选分享声明，旧输入序列化不新增空字段。声明绑定完整source（URL/revision/hash/page/locator/excerpt），记录人工declared_by/declared_at/reason与allow/withhold。声明变更不改变电气字段内容hash；来源内容变化仍失效两种声明。默认未声明不分享。保持明确无认证承诺。
2. 分享投影：集中构造面向分享的资料来源，不修改存储原值。被过滤的摘录保留内容hash/来源定位/省略原因，明确分享投影与原本地内容hash不相同，不能把过滤后的payload声称为原内容。历史使用当前明确撤回覆盖分享的需求需按具体来源绑定处理，不把新内容许可借给旧内容。
3. 写入/UI：完整人工录入和声明流程、条件与来源并排显示、乐观并发版本约束与原子保存；档案电气批准保持独立，不能以分享声明升级DRAFT。接入受管理保存/备份恢复。
4. 出口：当前/历史运行清单、白色/兼容离线报告、chat_responses及其派生文本逐一检查；共享时从受限投影重建派生文本，不能只对一个JSON字段做删除。原本地完整备份不伪称分享报告。
5. 验证：旧字段内容hash/批准声明兼容；允许/不允许/未声明/旧hash/错页/错版本/改摘录/撤回；实际API导出与离线原字节搜索，真实恢复、旧历史不改写、页面与下载可读。全量回归/实际浏览器/冻结交付后再将软件部分记为已实现。
