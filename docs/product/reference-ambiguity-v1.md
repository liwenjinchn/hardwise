## Goal / Context / Constraints / Done when

- Goal：同一行 Reference=U1、Refdes=C1 不按列优先级绑定；所有声明候选均不得据该行取得型号、额定值或可执行档案。
- Context：原始 source_fields 已保存列号/列名/值，但 CSV DictReader 和 XLSX 只选了一列位号，漏过其他候选。现有 BOM_IDENTITY_CONFLICT 可承载隔离，无需新增状态或数据库字段。
- Constraints：保留原始输入/来源及旧处理历史；不扩充设计注册表、不伪造器件；不把候选并集当已确认装配数量。其他独立检查继续；未声明精确依赖的拓扑仍沿用既有保守项目范围，不能据此声称全部 A10 最小依赖完成。
- Done when：全部已识别候选被隔离、原列定位可见、等价集合不误报、其他独立检查继续、修正后解除阻断，实际导入/重跑/离线/CSV和旧决定历史一致；正常样例不回归。

## 实现范围

1. 读取所有已支持的 Reference / References / Refdes / Designator 和位号声明。CSV/TSV仍要求原有支持表头，XLSX仍是位号/数量的有限格式；不承诺任意工作簿或未知别名。
2. 非空声明按既有 split_refdes 语法归一比较集合。大小写、顺序或分隔差异不制造冲突；空别名不与明确声明冲突。集合不一致时展开候选并集，仅用于隔离和诊断，不把任意候选作为真实绑定。同名重复列同样处理。未识别的非空竞争声明不能授权另一个有效声明。
3. Cadence固定布局文本报告保留位号列序号，按列合并一个物料项的续行声明，再比较完整集合；续行不是相互竞争的新列。报告仍保留原始文件和起始行定位；聚合声明不代替逐字原文件。
4. 复用既有身份冲突与档案隔离路径；候选行不进入可用 rows_by_refdes，不覆盖原网表字段，不生成有效数值/引脚规则。原始注册表引脚仍可展示，但没有获准电气评估。未知候选仍列 BOM-only，不进入设计注册表。
5. 不对冲突候选并集计算数量不符；已确认位号集合的数量核对、数量列矛盾诊断保持原合同。bom_refdes_count / 展开行统计包含观察到的候选，不是认证装配数量。
6. 身份冲突 producer 升至4，既有广域指纹回退保持。旧任务被身份冲突替代时记录 disappeared，保留原理由/运行/事件，不标为人工解决、不向新任务转移接受；更正后旧接受也不会自动复活。稳定身份冲突任务的3→4升级需复核一次。
