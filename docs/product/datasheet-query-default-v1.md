# 器件资料查询默认关闭

2026-10-25，用户选择：默认关闭；显式启用前展示接收服务和型号查询内容。此选择独立于云AI确认。

`serve-workbench`和`create_workbench_app`的`auto_datasheet_candidates`默认False。关闭时详情不查询；`/api/workbench/profile-gaps/{group_id}/datasheet-candidates`所有格式均403，不通过GET绕过默认开关。配置了资料服务密钥也不启用，云AI提问/确认也不启用。

显式添加`--auto-datasheet-candidates`表示为该服务进程启用资料查询；`--help`先披露接收地址`https://www.datasheets.com/api/v1/search`、器件型号/标识搜索词、limit/page与服务认证。启动输出在服务开放前再次披露，程序显式传True也会在接收请求前记录同一启动提示。白色“导入”页面显示已关闭/已显式启用及相同数据类别，关闭需移除开关并重启；不新增可远程更改此设置的API。

开启时，打开缺资料的MPN器件详情会自动查询，直接候选端点也可查询。这是服务进程级设置，切换其项目不会自动关闭；用户选择的页面内存确认时限仅属于云AI。此功能不上传网表或BOM原文件、不自动下载PDF、不把候选当工程批准。离线页面固定说明不查询，不将旧快照中“已启用”当实际连接状态。API调用者显式传True应先向使用者提供相同边界信息；启动日志不作为身份认证或工程批准。

基本本地流程及本地文档索引不依赖联网资料查询。其他显式CLI资料查询命令不在serve-workbench默认设置范围内，需用户主动运行；不能把本项表述为应用所有网络行为的总开关。
