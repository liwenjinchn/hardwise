# 剩余拓扑候选目录实施与验收

沿用用户已选规则目录驱动路线，第101阶段在执行前登记剩余九类家族的检查；不从执行结果或源码扫描动态推导分母。connector保持第100独立目录。

## 范围与实例

- buck固定登记开关输出连接、输出电感路径/选值、续流拓扑要求；缺开关脚时后三者不能从分母消失。完整执行路径补明确输出连接记录，原默认异常路径保留。
- 半桥驱动固定登记VCC/HIN/LIN/HO/LO/VS、自举观察和VB-VS；MCU固定登记既有两供电/复位/启动/两调试/两GPIO项。
- I2C mux的upstream_bus、control_pins和channel_pairs按既有分组检查登记，范围明确为该组汇总，不声称每脚一项或全功能。移位寄存器及I2C repeater依既有控制/端口检查登记。
- 二极管依档案diode_role枚举普通、双向TVS或LED分支；不按实际结果选择。MOSFET/BJT依固定端点及端间额定项登记。
- 规则定义显式列算法版本与作用域；候选实例包括家族，器件精确位号为owner。结果允许来源指向已注册邻居，但不能替代owner身份。

## 状态与兼容

先枚举，再执行；自身身份冲突仍保留未执行；DRAFT/项目身份暂停相关候选保持未知。LED有有效明确限流豁免时为N/A；其余缺前提不推断不适用。连接隔离只暂停触及的家族，实例不能因隔离或文案变化丢失。未知家族明确不支持，不造数量。生产默认报表/持久化不在本阶段切换。

## 验证

逐族正常、缺pin/电压、DRAFT/身份早退、连接隔离、不同分支和调序；缺/重复/孤立输出、错owner、未知版本、候选删减及作用域改变反例。遍历全部既有公开/合成设计核对关联、守恒与JSON往返。全量pytest/Ruff及受影响合同检查通过后提交。项目合并和全出口属于下一工作包；完整产品目标保持开放。
