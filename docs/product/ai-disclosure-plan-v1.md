## Goal / Context / Constraints / Done when

- Goal：启用真实模型前展示配置的接收服务及数据类别，由用户主动确认，未确认请求在模型调用前拒绝；基本本地闭环继续可用。
- Context：chat_service.py通过真实Runner发送提问、选中位号与最多6条各500字符历史；后续发送12工具中的真实返回载荷。当前页面仅解释边界声明；ChatRequest无确认字段，服务端没有对应前置检查。公开L78 SDK边界复现：GET状态200/模型调用0；无任何确认的POST聊天200/模型调用2，第二次含真实检查结果。注入记录器且禁止socket连接，实际网络尝试0；不是一次真实外发。
- Constraints：仅公开/合成材料；不展示密钥，不读取/输出真实.env。供应商不能由anthropic SDK名称推断，显示实际配置接收地址及“代理后续转发未知”的边界。默认不自动发送或回放问题；离线/fake与real明确区分；不把界面勾选记录当工程批准或强身份认证。
- Done when：实际前端在发送前可见服务/模型标识和类别；直接HTTP缺确认/过期确认均不触发客户端初始化或模型调用；已确认的当前项目仍走原Runner/Guard；变更项目或目的地后重新确认；无key/导入/检查/决策/导出不受阻；离线页面保留本地只读能力；异常/日志/导出无密钥。需相关后端/合同/浏览器验证，全量pytest/ruff及本地提交。

## 两种候选

| 方案 | 行为 | 取舍 |
|---|---|---|
| A，推荐 | 当前浏览器页面明确确认一次；刷新、项目或目的地/披露版本变化后重新确认 | 适合连续核查；仍须后端核对当前披露标识 |
| B | 每次发送前都再次确认，不自动提交刚输入的问题 | 更频繁提醒；每轮提问多一次操作 |

两种都必须有后端门槛。只加欢迎文案或只把发送按钮置灰不能满足直接HTTP边界。方案问题已发给用户；无答复不是选择。仓库AGENTS.md硬规则7：“present 2-3 solution approaches with trade-offs before starting implementation. Let the human choose the direction”。此次选择改变确认持续时间，需先选再实现；不是feature-dev凭空增加发布审批。

## 发送内容与接收方

首轮：静态系统规则、工具schema、所选模型标识、当前问题、选中位号、浏览器提供的短对话历史。后续轮次按工具选择，可能包含器件身份/BOM属性、引脚和网络连接/邻域/拓扑、确定性结果/输入事实/规则与证据引用、文档元数据或已配置检索返回的资料片段。不得写成“只发当前一句问题”。工具内容可带文件定位/路径、页码和来源token，应披露为来源信息；目前不是原文件自动上传，但提问和历史中的用户文本也会发送，不能承诺设计信息绝不离开本机。

将接收地址的安全显示值与实际SDK配置绑定，移除URL userinfo、query和fragment；不将含密钥的任意配置原样传给浏览器。配置格式无效时拒绝AI并给出不含原值的说明。未配置key仍显示AI不可用及基本功能可用，不为展示说明初始化网络。真实接收地址可能是第三方代理或本机中转，标签只能声称配置地址，不能证明后端模型品牌/下游目的地。

## 拟实施边界（待选择后再落地）

1. 服务端提供安全的披露描述：real/fake/snapshot、配置的接收方、所选模型、数据类别、披露版本及当前上下文绑定的opaque标识。离线/合成模式明确不调用真实服务；不把real描述封存为当前离线连接承诺。
2. 浏览器先展示说明；未确认时不向chat端点发问题。按A或B管理确认，仅存当前页面内存，不写工程决定日志、档案批准或备份。失败不自动重试/发送；建议问题按钮和Enter键遵守同一入口。
3. ChatRequest携带当前已确认披露标识；后端在ask/Runner/Deferred客户端创建前验证。旧客户端缺失标识明确拒绝。陈旧/其他项目/失效目的地标识不能继续；返回可重取说明的非泄密错误。此标识是防止误发送的前置合同，不能作为授权凭证、CSRF防护或可证明真实人已阅读的审计认证。
4. 核对dotenv配置时序。当前服务构建时load_dotenv用于router，首次模型调用时_default_client又加载一次。实现须消除“展示地址A但延迟客户端实际读取B”的差异：展示和发请求使用同一份有效配置快照，配置变化重新生成披露并要求确认；不得只比较浏览器展示字符串。已有注入客户端测试必须明确指定fake记录器，不从未知注入对象臆断真实服务地址。
5. 不修改确定性判定/人工处理/原始输入归属。导入切换后的上下文绑定使用当前真实来源，不依赖用户可伪造的位号或前端项目名。
